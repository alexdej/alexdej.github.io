# Alex DeJarnatt

I'm an independent software developer. These days most of my work is crossword data and tools.
Before this I worked at HQ Trivia, Vine, Google, Microsoft and drugstore.com. See my [resume](/resume.html).

## Crosswords

[The Cross Reference](https://crosswordreference.com)
: A reference site for crossword answers and clues, built around the connections between puzzles.

[Every Puzzle Project](https://blitz.xwordapp.com/)
: Bringing old crosswords back from paper and page scans. Read the [blog](https://blitz.xwordapp.com/blog/).

[xd](https://xd.saul.pw/)
: A futureproof crossword corpus and toolset, which I maintain with [Saul Pwanson](https://saul.pw/).

[puz.py](https://github.com/alexdej/puzpy)
: A Python library for reading and writing Across Lite .puz files.

[xword-dl](https://github.com/thisisparker/xword-dl)
: A command-line tool for downloading crosswords. I'm a contributor.

## Other projects

[hodoku-py](https://alexdej.github.io/hodoku-py/)
: A Python port of HoDoKu's sudoku engine: solver, difficulty rating, hints and puzzle generator.

pytest plugins
: Static analysis for C and C++ from pytest: [clang-tidy](https://github.com/alexdej/pytest-clang-tidy), [cppcheck](https://github.com/alexdej/pytest-cppcheck) and [cpplint](https://github.com/alexdej/pytest-cpplint).

[claude-scrollback](https://alexdej.github.io/claude-scrollback/)
: A lightweight web viewer for Claude Code session transcripts.
