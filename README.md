# alexdej.com

Edit `index.md` (home) or `resume.md`, then push to `main`. GitHub Pages rebuilds the site with Jekyll.

- A project is a link on one line and `: description` on the next.
- `_layouts/default.html` is the page shell, and `style.css` is the styling.
- `{: .email}` after a link makes it the click-to-reveal email link (`email.js`).
